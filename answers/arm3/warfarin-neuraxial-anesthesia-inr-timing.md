# 华法林停5天就能穿？先看INR

华法林术前停多久才能做椎管内麻醉？

Miller's Anesthesia（10th Edition）给的答案是：**≥5天**，而且穿刺前要复查**INR确认恢复正常**。

注意，这是两个条件，不是一个。

## 结论先摆这儿

决策锚点是"INR正常化"，不是日历上数够5天。停药天数只是下限，不是终点。教科书原文写得很清楚：warfarin should be discontinued **≥5 days** before surgery，and a repeat preoperative INR should confirm a normalized value before neuraxial blocks are performed。

但卡片没给"INR正常化"的具体数值阈值。也没给拔管前复测时点、拔管后重启华法林的间隔。这些得按本院SOP和原始指南核对，本文不替指南设数。

## 为什么是5天，不是24小时

椎管内穿刺和置管，本质是机械性破损硬膜外静脉丛。止血靠两样：血小板栓，和凝血级联。

华法林抑制维生素K环氧化物还原酶，压低Ⅱ、Ⅶ、Ⅸ、Ⅹ和蛋白C/S的γ-羧化，凝血酶生成延迟。

关键在时相。华法林的效应受已合成凝血因子半衰期支配——Ⅶ最短，约4–6小时；Ⅱ最长，60小时量级。所以INR回落以天为单位，不以小时计。

这就是"≥5天+复查INR"的药理依据。停24–48小时就穿，逻辑上站不住。

还有一层：穿刺时凝血酶生成不足→血肿形成；血肿扩大压迫脊髓→缺血窗口以小时计。所以"穿刺前INR正常化"和"拔管前再确认凝血状态"是同源逻辑。这是病理生理推演，卡片没有直接验证。

## 临床怎么把握

华法林属于"必须术前暂停"那一类。Miller's另一个单元说得很直白：维生素K拮抗剂和DOAC，除非是极轻微操作、患者无出血危险因素、且**不考虑椎管内麻醉**，否则应术前暂停。椎管内麻醉本身就构成"不能继续抗凝"的情形。

几个同类对照数值，卡片里有，列出来方便对照，但都不是华法林：

- 预防剂量LMWH至椎管内阻滞：**≥12小时**
- 治疗剂量LMWH（含桥接）：**≥24小时**
- 术前静脉普通肝素至脊麻/硬膜外：**≥6小时**

DOAC别往华法林这套表里套。Br J Anaesth 2025那篇综述（PMID:41073233）只给了方向性结论——DOAC增加椎管内镇痛和深部外周神经阻滞的出血风险，没给具体停药间期。华法林的"≥5天+INR复核"不能外推到DOAC。

停药期血栓风险要量化，不能笼统说"桥接"。首发无诱因VTE停抗凝后的复发风险有系统评价（BMJ，PMID:31340984）；VTE-PREDICT评分能个体化估5年复发和出血绝对风险（Eur Heart J，PMID:36648242，n=15,141）。桥不桥、桥多久，落到个体绝对风险差上，不是群体平均值。

跟患者谈话要分母。单中心96,103例全髋/膝关节置换椎管内麻醉连续病例分析（Br J Anaesth，PMID:42150958）给了当代操作和人群特异的血肿发生率估计。这是最有力的数字。

## 还有哪些不确定

**天数还是INR为准？** 卡片层面Miller's两个都给了，但没说INR正常化的判定阈值，也没说不同INR基线（2–3 vs 3.5以上）要不要延长停药。B源按INR分层给了5/5–6/6–7天的表，卡片无对应数据，属模型意见，未溯源，不采信。

**DOAC领域的分歧是明摆着的。** 2025年Br J Anaesth综述和2026年髋部骨折国际共识（PMID:38319797）并存，后者明确写"No consensus was achieved regarding timing of spinal anaesthesia"。DOAC证据更厚，椎管内时机仍是共识缺口。华法林的证据强度不会更好。

**桥接的净获益，卡片级证据不支持。** 知识库只有复发和出血的预测工具，没有桥接vs不桥接的RCT。"停5天+桥接"是惯例，不是本卡库能证实的优选策略。

**单中心数据别当个体承诺。** PMID:42150958是单中心回顾性连续病例，血肿是罕见事件，置信区间宽。

卡片库没见到华法林停药与椎管内麻醉之间的重大直接争议文献。上面这些分歧，多是邻近领域外推。
