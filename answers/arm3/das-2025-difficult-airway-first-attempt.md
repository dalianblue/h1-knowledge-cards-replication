# DAS 2025把视频喉镜推上首次插管C位，但"一律首选"还没说服所有人

DAS 2025指南把视频喉镜从"备选/救援工具"前移为成人首次气管插管的默认首选。

这不是因为"VL一定比DL好"。底层逻辑是范式换了：从"救援失败"转向"首次即成功、主动预防失败"。

首次尝试做对，比失败后补救更能改善结局。指南同时把更早的神经肌肉阻滞、修订的ABCD救援路径、标准化的垂直切口紧急前颈通路，一并纳入这个范式（Br J Anaesth 2025社论，PMID:41339170，certified）。

先说清楚一件事：本卡片库里支撑"VL优于DL"的具体效应量——成功率、低氧血症下降幅度——原文chunk残缺，知识库暂无完整可引数值。下文凡涉及数字，按卡片原文如实标注或明示缺口。

## 结论先摆出来

Plan A条目写得很直白："a videolaryngoscope should be used first line to facilitate tracheal intubation whenever possible"，并称有强证据支持其提高首次成功率、减少低氧血症、降低食管内插管风险（DAS 2025 Plan A原文chunk，unverified——该卡无PMID，数值与结论按来源等级降级呈现）。

方向可信。幅度，在本卡库内不可引用。

## 为什么"第一次"是关键时点

每次尝试都会降低后续成功率。这是指南把资源前置到首次尝试的直接依据（Plan A原文chunk，unverified；具体效应量卡片残缺）。

低氧血症一旦在尝试过程中出现，处理优先级立即转为面罩通气给氧，插管尝试让位（同上）。所以"减少首次尝试中的低氧"本身就是结局指标，不是附带好处。

结构上，直接喉镜依赖口-咽-喉三轴线对齐与声门暴露。颈椎制动、肥胖、张口受限、小下颌，都会破坏这个几何条件。VL通过镜片尖端摄像把声门"搬到屏幕"，降低对轴线对齐的依赖（教科书机制；本卡库无直接机制验证，属机制推演）。

共享视野是另一个实际收益：操作者与助手同屏，外部喉部按压、吸引、导管塑形可以实时纠错（机制推演，卡库无直接验证）。

## 临床怎么把握

**限次：3+1。** 最多3次由原操作者尝试，第4次须由更有经验者执行（Plan A原文chunk，unverified）。

**失败可以提前判定。** 不必用满次数——当找不到可改进的环节，或继续尝试可能导致并发症（气道梗阻、面罩通气失败），Plan A可在任何时候宣告失败（同上）。

**肌松别拖。** 面罩通气确认后不应延迟给予神经肌肉阻滞剂；插管条件优化项里明确包含"优化神经肌肉阻滞"（同上）。目的是缩短"无肌松-插管条件不佳-反复尝试"这条链。

**确认插管靠两样：波形二氧化碳+直视。** 波形capnography确认呼气末CO₂，同时看到导管通过声门。仅capnography不能排除导管进入支气管或咽部（同上）。

**首次尝试的定义**：一次器械/引导器（或两者）置入气管导管并经波形capnography确认（同上）。

## 还有哪些不确定

**"一律VL首选"有公开反对意见。** 2022–2023年BJA多篇通信，标题就是"Use of videolaryngoscopy as the first option for all tracheal intubations: not so fast"，另有回应及谈技术获益/简化算法的反方文章（PMID:36435665、PMID:36307273、PMID:36740531，均certified）。这些卡片仅存题录，具体论据本卡库未见。

**证据等级有断层。** Plan A多数操作性条目来自unverified原文chunk（无PMID），"强证据"表述无法在卡内溯源到具体RCT；社论（PMID:41339170）只确认范式转变，未提供效应量。

**换设备不等于换能力。** 有随机模拟研究专门考察VL培训后困难插管技能的迁移（PMID:32450875，certified）。指南落地依赖结构化教育包（DAS 2025 Education Package，unverified）。

**eFONA解剖终点仍在细化。** 2025版后有针对紧急前颈通路解剖终点的专门通信（PMID:41475932，certified）。

与2015版的关系也值得说一句：2015版已提出以视频/纤维光学引导插管取代盲探bougie与经声门上气道盲插，并推荐第二代声门上气道、失败时唤醒患者、环甲膜切开作为首选救援（PMID:26556848，certified）。2025版的"新"不在技术本身，而在把VL从"替代盲探的手段"升格为"默认起点"。

证据就这样。方向清楚，幅度待补，争议还在台面上。
