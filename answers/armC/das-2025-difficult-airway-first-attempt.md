# DAS 2025把视频喉镜推上一线，但"全部插管首选VL"仍有人反对

DAS 2025指南的核心变化，不是某个器械升级，而是把**首次尝试成功**抬到了最高权重。指南原文写得很直白："a videolaryngoscope should be used first line to facilitate tracheal intubation whenever possible"（DAS 2025 Plan A）。

结论先给：成人气管插管，能上视频喉镜就上视频喉镜。

理由不复杂。指南明确说，每一次追加插管尝试都会延长操作时间、降低后续插管成功概率（DAS 2025 Plan A）。反复尝试叠加的不是时间，是低氧、水肿、出血和误吸。把"看得更清、一次成功概率更高"的器械前置，逻辑就在这里。

需要说清楚：卡片库里没有VL与DL首次成功率的效应值、样本量或置信区间。本文不搬具体数字。

## 机制上发生了什么

直接喉镜靠口咽轴线机械对齐，嗅物位对不上，声门就看不见。视频喉镜把成像传感器放在镜片前端，视野获取不再完全依赖轴线对齐。这是教科书级原理。

肌松时点也前移了。2025版不因担心面罩通气困难而延迟给药，让插管落在肌松充分、声门开放的窗口内，避免"浅肌松下勉强置镜—视野不佳—反复尝试"的循环。面罩通气有效性仍须确认。

## 临床怎么把握

**3+1原则不变**：初始操作者最多3次，第4次换更有经验的同事。每次尝试都必须是"经过优化的尝试"。

**失败定义前移**：Plan A失败可在任何时候宣告，不必等次数用尽。找不到可优化环节，或继续尝试可能导致气道梗阻、面罩通气失败，就该转换。

**确认手段升级**：波形二氧化碳图确认，辅以视频下见导管通过声门的直视确认——二氧化碳图不能排除导管入支气管或咽部。

**氧合贯穿全程**：预氧合推荐高流量氧疗，整个气道管理过程优先持续给氧。

**补救路径重构**：ABCD框架修订，eFONA标准化为垂直切口技术（PMID:41339170）。

## 还有哪些不确定

"全部插管首选VL"有公开反对声音。Br J Anaesth 2022年刊出"Use of videolaryngoscopy as the first option for all tracheal intubations: not so fast"（PMID:36435665），后续还有通讯（PMID:36307273、PMID:36740531）。DAS 2025用"whenever possible"保留了弹性，但指南正文与反对意见之间的证据权重分配，卡片库给不出来。

推荐强度与证据等级也有错配。Plan A相关卡片信任级为unverified，支撑范式转变的社论（PMID:41339170）是叙述性评论，不是系统评价。

实施层面，教育包文献直言指南推荐常难转化为广泛实践，障碍包括认知差异、技能差异与实施策略不足。

特殊人群证据缺位。新生儿仅见纤支镜经喉罩插管个案（PMID:36459113），儿童有VL联合纤支镜的单中心分析（PMID:40402023），都不足以支撑"儿童一线VL"。成人推荐向儿科外推，要谨慎。

证据就这样。用不用，看科室胜任力和具体病人。
