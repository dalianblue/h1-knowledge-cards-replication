# 重型TBI凝血病为何不能照多发伤管

**核心差异：TBI凝血病是“脑源性”的，多发伤凝血病是“失血+休克+稀释性”的。机制不同，处理逻辑就不同。**

## 一、机制不同

| | 重型TBI凝血病 | 多发伤凝血病 |
|---|---|---|
| 始动因素 | 脑组织损伤释放TF、脑磷脂、组织型纤溶酶原激活物（tPA） | 失血性休克、组织灌注不足、血液稀释 |
| 核心表型 | **高纤溶 + 内皮糖萼损伤 + 血小板功能障碍** | 消耗性凝血病 + 稀释性凝血病 + 酸中毒 |
| 纤溶状态 | 早期即**纤溶亢进**（tPA飙升，PAI-1相对不足） | 晚期才纤溶抑制 |
| 血小板 | 数量可正常但**功能严重受损** | 数量下降为主 |

TBI后数分钟内，损伤脑组织即释放大量tPA入血，同时血脑屏障破坏使脑磷脂入循环，直接激活凝血并触发高纤溶。这与多发伤“先出血液稀释、后消耗”的时序完全不同。

## 二、处理不能照搬的关键点

**1. 氨甲环酸（TXA）时机窗口不同**
- TBI：伤后**3小时内**给药获益明确（CRASH-3），超过3小时可能有害。剂量1g/10min静注+1g/8h。
- 多发伤：MATTERs方案强调“越早越好”，但主要针对出血死亡，逻辑是抗纤溶止血。
- **不能因为“多发伤也打TXA”就在TBI超窗后照打**——TBI晚期纤溶已非主导，TXA反而增加血栓风险。

**2. 目标血压/灌注压不同**
- TBI：必须维持**CPP 60–70 mmHg**（MAP≥80），避免低血压二次脑缺血。液体首选等渗晶体，**慎用大量胶体**。
- 多发伤：允许性低血压（收缩压80–90）直到止血，优先限制性液体复苏。
- **照多发伤做允许性低血压 = 直接加重TBI继发脑损伤。**

**3. 血制品策略不同**
- TBI：血小板功能比数量更重要，**不推荐常规预防性输注血小板**（PATCH试验：无获益反增死亡）；纤维蛋白原目标≥1.5–2.0 g/L；**不推荐常规用rFVIIa**。
- 多发伤：按大量输血方案（1:1:1）积极输注，血小板<50×10⁹/L即补。
- **照多发伤1:1:1猛灌 = TBI患者容量过负荷、加重脑水肿。**

**4. 监测手段不同**
- TBI：需**TEG/ROTEM**指导，重点看纤溶指标（LY30）和功能性纤维蛋白原；反复头颅CT评估出血进展。
- 多发伤：常规凝血+血气+乳酸即可驱动。
- TBI凝血病**常规凝血四项常“正常”**，照多发伤只看PT/APTT会漏诊。

## 三、一句话总结

**多发伤凝血病是“失血性休克的下游事件”，治的是容量和消耗；TBI凝血病是“脑损伤的直接后果”，治的是纤溶亢进、内皮保护和脑灌注。** 把TBI当多发伤管，最危险的三个错误是：允许性低血压、大量晶体/胶体扩容、超窗或盲目抗纤溶——每一个都直接增加颅内出血和继发脑损伤。
