# 甲氨蝶呤（MTX）麻醉风险要点

## 一、核心风险机制
- **叶酸拮抗**：抑制二氢叶酸还原酶，影响DNA合成与修复
- **多系统毒性**：骨髓抑制、肝毒性、肾毒性、肺毒性、神经毒性
- **药物相互作用**：与麻醉药物、NSAIDs、弱酸性药物相互作用

## 二、术前评估要点
| 项目 | 阈值/要点 |
|------|----------|
| 血常规 | Hb≥80g/L，ANC≥1.5×10⁹/L，PLT≥80×10⁹/L（低于此值延期择期手术） |
| 肝功能 | ALT/AST>2倍正常上限需评估；胆红素升高提示肝损 |
| 肾功能 | eGFR<60ml/min需减量/停药；MTX主要经肾排泄 |
| 肺功能 | 有MTX肺病史者查肺功能+胸部CT |
| 血药浓度 | 大剂量MTX后需待浓度<0.1μmol/L方可择期手术 |
| 末次给药 | 低剂量（≤25mg/周）：停药≥1周；大剂量：待毒性恢复 |

## 三、麻醉药物相互作用
1. **NSAIDs/阿司匹林**：竞争肾小管分泌，升高MTX浓度→避免围术期使用
2. **弱酸性药物**（如硫喷妥钠）：减少MTX肾排泄
3. **丙泊酚/阿片类**：无直接禁忌，但需注意肝肾功能受损时药代改变
4. **笑气（N₂O）**：抑制甲硫氨酸合成酶，与MTX叶酸拮抗**叠加**→**建议避免**
5. **顺阿曲库铵**：肾功能不全时作用延长
6. **青霉素类**：减少MTX肾排泄，需警惕

## 四、麻醉管理步骤
1. **术前**：纠正贫血/血小板减少；停用NSAIDs≥5个半衰期；备血
2. **诱导**：避免笑气；肝肾功能不全者减量丙泊酚/阿片类
3. **维持**：监测体温、血糖；避免低血压（肾灌注↓→MTX蓄积）
4. **肌松**：肾功能不全优选顺阿曲库铵（Hofmann消除）或罗库溴铵+舒更葡糖
5. **液体管理**：维持充足尿量（≥0.5ml/kg/h），碱化尿液可促MTX排泄
6. **术后**：多模式镇痛**避免NSAIDs**；监测骨髓抑制征象（感染、出血）

## 五、特殊注意
- **椎管内麻醉**：血小板<80×10⁹/L或凝血异常→禁忌
- **MTX肺病**：避免高浓度氧、限制液体，术后警惕呼吸衰竭
- **甲酰四氢叶酸（亚叶酸钙）**：大剂量MTX后必要时围术期继续解救
- **急诊手术**：MTX毒性期（黏膜炎、骨髓抑制）→权衡利弊，备血/血小板、广谱抗生素

## 六、关键阈值速记
- PLT<80×10⁹/L：禁椎管内麻醉
- eGFR<60：MTX需减量，麻醉药物经肾排泄者调整
- 大剂量MTX后血药浓度>0.1μmol/L：延期择期手术
- 末次低剂量MTX：停药≥1周再择期手术

> **总结**：MTX麻醉风险核心在于**骨髓抑制、肝肾毒性及药物相互作用**。围术期避免NSAIDs与笑气，充分评估血常规/肝肾功能，保证肾灌注与尿量，个体化调整麻醉药物剂量。
