# 170kg 骨盆骨折术后当晚肺栓塞：抗凝漏在哪？

## 一、核心判断：漏在“预防窗口期”与“剂量-体重错配”

骨盆骨折是 VTE 极高危（Caprini 常≥9 分），术后当晚即发生 PE，说明血栓多在**术前卧床期**已形成，而围术期抗凝存在空窗。170kg（BMI 常>50）使标准预防剂量严重不足。

## 二、可能的漏点（按时间轴）

| 环节 | 常见缺陷 |
|---|---|
| 入院—术前 | 因“骨折出血风险”延迟启动药物预防；仅用弹力袜/IPC，未用 LMWH |
| 术前停抗凝 | 术前 12–24h 停 LMWH 后未桥接，形成 1–2 天空窗 |
| 术中—术后 | 术后 6–12h 内因“切口渗血/硬膜外”未恢复抗凝，而血栓已脱落 |
| 剂量 | 按标准 40mg qd 给药，170kg 下明显不足（见下） |
| 监测 | 未测抗-Xa 活性，未评估肾功能（CrCl）调整 |

## 三、剂量与阈值（关键）

- **LMWH 预防**：肥胖患者建议 **依诺肝素 40mg q12h** 或 **0.5mg/kg/日**；170kg 按体重可达 60–80mg/日以上，标准 40mg qd 属**剂量不足**。
- **抗-Xa 目标（预防）**：给药后 4h 峰值 **0.2–0.4 IU/mL**（q12h 方案）；不足则上调。
- **肾功能**：CrCl<30 用普通肝素或减量；肥胖者按**实际体重**计算 CrCl 常高估，需谨慎。
- **硬膜外/椎管内麻醉**：置管/拔管前后需按指南间隔（依诺肝素预防剂量拔管后≥4h、置管前≥12h），此间隔常被压缩导致“怕出血而不抗凝”。

## 四、可操作的补救步骤

1. **确认诊断**：CTPA 确诊，评估右心负荷（超声）、血压、氧合，分层是否高危/中高危。
2. **抗凝启动**：无禁忌即**治疗剂量** LMWH（依诺肝素 1mg/kg q12h，按实际体重，170kg 需评估上限，常封顶或监测抗-Xa 0.6–1.0 IU/mL）或普通肝素静脉（肥胖、肾功能不全优选，便于滴定）。
3. **高危 PE**（休克/持续低血压）：考虑溶栓，但术后当晚**出血风险极高**，需多学科权衡，优先介入取栓/ECMO 评估。
4. **监测**：血小板（HIT）、Hb、抗-Xa、肾功能、下肢超声。
5. **预防复盘**：此后改为 q12h 或体重调整剂量 + IPC 联合，记录抗凝起止时间表。

## 五、结论

漏点不在“没用药”，而在**术前空窗 + 术后延迟 + 标准剂量对 170kg 严重不足 + 未做抗-Xa 监测**。对极高危肥胖骨盆骨折，应**入院即评估、术前不轻易全停、术后尽早（6–12h 评估出血后）恢复体重调整剂量**，并以抗-Xa 指导滴定。

> 具体用药与剂量须结合患者出血风险、肾功能及本地指南，由主管团队个体化决定。
