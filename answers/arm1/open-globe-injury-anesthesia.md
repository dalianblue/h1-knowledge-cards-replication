# 眼球破裂+脑挫裂伤行眼球摘除麻醉要点

## 一、总体原则
- **先救命后治眼**：脑挫裂伤优先评估，眼摘为限期手术，颅内压未控、血流动力学不稳时暂缓。
- 多学科协作（神经外科、眼科、麻醉），术前CT复查颅内情况。

## 二、术前评估
- **神经**：GCS、瞳孔、颅内压（ICP）征象；颅高压（>20 mmHg）先降颅压再麻醉。
- **气道**：颌面/颅底骨折、误吸风险，评估困难气道。
- **血流动力学**：维持脑灌注压 CPP=MAP−ICP ≥60 mmHg。
- **眼**：确认破裂、禁食、避免眼压升高（防眼内容物脱出）。

## 三、麻醉选择
- **首选全身麻醉**（气管插管），避免患者体动、呛咳致眼压骤升及误吸。
- 颅高压者**避免**氯胺酮、琥珀胆碱（升ICP/IOP）；快速序贯诱导可用罗库溴铵（1.2 mg/kg）或顺阿曲库铵。
- 诱导：丙泊酚 1.5–2.5 mg/kg + 瑞芬太尼，**避免**面罩正压通气过高致眼压升高，插管前充分肌松。
- 维持：丙泊酚/七氟烷 + 瑞芬太尼，维持MAP在基线±20%，避免低血压（脑缺血）与高血压（再出血/眼压）。

## 四、术中管理
- **通气**：维持PaCO₂ 35–40 mmHg（颅高压者可短暂30–35），避免高碳酸血症升ICP。
- **体位**：头略抬高15–30°，避免压迫眼球。
- **液体**：等渗晶体，避免低渗液（脑水肿）；血糖维持4.4–10 mmol/L。
- **监测**：有创动脉压、尿量、体温；必要时ICP监测。
- 眼摘操作牵拉眼肌可致**眼心反射**（心动过缓），备阿托品 0.5 mg，及时提醒术者。

## 五、苏醒与术后
- 平稳拔管，避免呛咳、躁动（升ICP/IOP）；颅高压或意识差者**延迟拔管**。
- 镇痛（阿片类）+ 止吐（昂丹司琼 4 mg），防恶心呕吐升眼压。
- 术后神经功能监测，警惕迟发颅内出血。

## 六、关键阈值速记
| 项目 | 目标 |
|---|---|
| CPP | ≥60 mmHg |
| PaCO₂ | 35–40 mmHg |
| MAP波动 | 基线±20% |
| 血糖 | 4.4–10 mmol/L |
| 拔管 | 意识清、无颅高压 |
