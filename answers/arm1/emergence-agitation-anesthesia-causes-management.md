# 全麻苏醒期躁动（EA）的原因与处理

## 一、定义与高危因素
苏醒期躁动指全麻苏醒后30分钟内出现的**躁动不安、无目的挣扎、不配合、呻吟**，可伴交感兴奋（心率↑、血压↑）。多见于**儿童、青年男性**，以及**七氟烷/地氟烷吸入麻醉**、**短小手术**（如扁桃体、疝、眼科）。

## 二、常见原因（按“痛、尿、氧、药、脑”排查）

| 类别 | 具体原因 |
|---|---|
| **疼痛**（最常见） | 切口痛、引流管、导尿管刺激 |
| **膀胱/胃肠** | 尿潴留（尤其腰麻+全麻、抗胆碱药后）、胃胀气 |
| **缺氧/通气** | 低氧、CO₂蓄积、气道梗阻、肌松残余（TOF<0.9） |
| **药物** | 吸入麻醉（七氟烷>2 MAC快速洗脱）、阿托品、氯胺酮、苯二氮䓬类、肌松拮抗不充分 |
| **电解质/代谢** | 低钠、低血糖、酸中毒、体温异常 |
| **神经系统** | 颅内压增高、脑缺血、癫痫、术前焦虑/认知障碍 |
| **环境** | 气管导管、吸痰、约束、噪音、陌生环境 |

## 三、处理步骤（先排除危及生命，再对症）

**1. 立即评估（ABC）**
- 吸氧、监测SpO₂/EtCO₂、心率血压；**排除低氧、气道梗阻、肌松残余**（必要时TOF监测，新斯的明0.04–0.07 mg/kg + 阿托品）。
- 查血糖、电解质、体温；疑颅脑问题者查瞳孔、神经体征。

**2. 镇痛优先**
- 评估疼痛（FLACC/面部量表），给**阿片类**：芬太尼0.5–1 μg/kg 静注，或舒芬太尼0.1–0.2 μg/kg；儿童可用对乙酰氨基酚15 mg/kg 或酮咯酸0.5 mg/kg。
- 区域阻滞/切口局麻浸润可显著降低EA。

**3. 解除刺激源**
- 尿潴留→导尿或诱导排尿；胃胀→胃肠减压；松解约束、减少吸痰、降低环境噪音。

**4. 药物镇静（在排除缺氧、镇痛充分后）**
- **丙泊酚** 0.5–1 mg/kg 静注（最常用，起效快、可重复小剂量）；
- 或**右美托咪定** 0.3–0.5 μg/kg 10分钟泵入（减少谵妄、呼吸抑制轻）；
- 无效或疑阿片过量→**纳洛酮**0.04 mg 递增；苯二氮䓬过量→氟马西尼0.2 mg。
- 避免常规使用氟哌利多（QT）。

**5. 预防（高危患者）**
- 儿童七氟烷麻醉联合**丙泊酚诱导/维持**或**右美托咪定0.5 μg/kg**术前给药；
- 充分镇痛（多模式）、避免肌松残余、术中维持适宜麻醉深度（BIS 40–60）、术后早拔管并减少刺激。

**关键原则：先找原因（尤其缺氧、疼痛、尿潴留），再镇静；切忌在未排除低氧/气道问题时盲目加深镇静。**
