# 三支重度狭窄暂不PCI，胸科术前访视要点

## 一、核心风险判断
- **主要矛盾**：胸科手术（开胸/肺切除）应激大、失血与液体 shifts 明显，而冠脉为三支重度狭窄、未血运重建，围术期 **心肌缺血/心梗/心衰/恶性心律失常** 风险显著升高。
- 访视目标：明确狭窄解剖与缺血负荷、评估左室功能与代偿、判断“能否耐受”及“是否需要术前再评估心脏团队”。

## 二、病史与资料核实
1. 冠脉造影报告：三支狭窄具体部位与程度（左主干？近端LAD？）、是否优势型、有无侧支；**左主干≥50%或前降支近端≥70%属高危**。
2. 是否做过 **FFR/IVUS**、负荷试验（缺血范围）、心脏MRI/核素。
3. 症状：加拿大心绞痛分级（CCS）、有无静息痛/夜间痛、活动耐量（METs）、有无心衰症状（NYHA）。
4. 用药：双抗？他汀？β阻滞剂？硝酸酯？**抗血小板停药时机**需与心内科/外科共同决定。
5. 合并症：糖尿病、COPD、肾功能、贫血、房颤、瓣膜病。

## 三、体格与辅助检查
- 生命体征、颈静脉、肺部啰音、下肢水肿、外周血管。
- **静息心电图**（对比既往）、**超声心动图（EF、节段性室壁运动、瓣膜、肺动脉压）**。
- 血常规、凝血、肾功、电解质、血气、肺功能（胸科必需）。
- 必要时 **负荷超声/核素** 评估缺血范围（若条件允许且不延误手术）。

## 四、多学科决策（关键步骤）
- **心脏团队（心内科+心外科+麻醉+胸外科）会诊**：判断“暂不PCI”是否为计划性（如待外科问题解决后择期血运重建）还是被迫。
- 明确：**是否需要术前CABG/PCI**；若确需限期胸科手术，则制定“高危麻醉管理方案”。
- 与患者/家属充分沟通围术期心脏事件风险并签署知情。

## 五、麻醉与围术期预案（访视中落实）
1. **监测**：有创动脉、中心静脉、**术中TEE或经食道/经胸超声**（按条件）、ST段连续监测、体温与容量监测。
2. **血流动力学目标**：维持冠脉灌注压（MAP≥65–70 mmHg）、避免心动过速（HR控制）、避免低血压与贫血；**Hb维持≥80–90 g/L（高危者偏上限）**。
3. **药物**：术前β阻滞剂继续（避免骤停）；他汀继续；硝酸酯备用；**双抗停药按心内科意见**，必要时桥接。
4. **液体管理**：限制性输液，避免容量过负荷诱发心衰；必要时利尿。
5. **术后**：ICU监护、镇痛充分（硬膜外/椎旁阻滞减少应激）、早期识别缺血（肌钙蛋白、ECG）。

## 六、访视记录结论模板
> “患者三支重度狭窄（具体…），EF…，暂未血运重建。胸科手术围术期心肌缺血/心衰风险高。已行心脏团队会诊，计划…。麻醉采用…监测与血流动力学目标…。已告知风险并签署知情。”

**要点**：访视不是“能不能麻”，而是**把风险量化、把团队拉齐、把监测与目标写清楚**。
